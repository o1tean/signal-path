# Signal Path — conventions for anyone (human or agent) working in this repo

Branch `v2` is a rebuild. Read `docs/v2/architecture.md` (stack, routes, access boundary, schema) and `docs/v2/offer.md` before touching code or copy. Customer-facing text must follow `docs/v2/copy-brief.md`.

## Stack rules
- Astro ^7 + React ^19 islands + Tailwind ^4 + shadcn/ui. npm only. Do not add a package without a reason that fits the architecture doc; never add a second UI kit, state library, or payment provider.
- Verify Astro/Supabase/Stripe APIs against current docs (https://docs.astro.build/llms-small.txt, https://supabase.com/docs/guides/auth/server-side, https://docs.stripe.com/checkout) rather than memory. Record anything you verified in the "Verified APIs" section below so others don't re-check.
- `src/content/lessons/*.mdx` is the course. Frontmatter must satisfy `src/content.config.ts`. Lesson H2 order: Outcome · Before you start · Understand · Predict and practise · Check yourself · Keep evidence · Continue.
- Paid material (lesson bodies of `access: 'paid'`, `src/data/quiz/paid/*`, `private/downloads/*`) must never be reachable without `hasAccess()`; never import paid quiz files from client code; never copy them into `public/`.
- Widgets are vanilla TypeScript modules in `src/widgets/` exporting `mount(el, opts) => cleanup`. They talk to the learner store through `src/lib/learner.ts` only. Use `<Widget name="…" />` in MDX.
- Tokens live in `src/styles/global.css` (`@theme` + shadcn vars). No hard-coded colours in components; use semantic classes (`bg-primary`, `text-muted-foreground`, …). Light and dark must both work; `data-theme` on `<html>`, stored under `signalpath.theme`.
- Motion: CSS first, `motion/react` only for things CSS can't do; honour `prefers-reduced-motion` and the site motion toggle.
- Accessibility: landmarks, labelled controls, visible focus, keyboard paths for every interactive tool, `aria-live` for scores. Minimum touch target 44px.
- Tests: `npm run check`, `npm test`, `npm run build` must pass before you report done. Add a unit test for any logic with a branch.
- Commit only when asked. Never commit secrets; `.env` is ignored, `.env.example` is the contract.

- astro@7.3.8: client directives `client:idle`, `client:visible`, `client:media={QUERY}`, `client:only={FRAMEWORK}` (use `client:only="react"` for islands that read localStorage). (https://docs.astro.build/en/reference/directives-reference/, 2026-10-12)
